# 💰 Expense Tracker (Python)

A simple command-line application to track your daily spending. Built with
**pure Python** (standard library only — nothing to install).

## Features
- ➕ Add expenses (date, category, description, amount)
- 📋 View all expenses in a table
- 📊 See spending grouped by category
- 💵 See total spending
- 💾 Data saved automatically to a `expenses.csv` file

## How to Run

You need Python 3 installed. Then:

```bash
cd python-expense-tracker
python3 expense_tracker.py
```

Follow the on-screen menu (type a number 1–5 and press Enter).
