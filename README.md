# 🎓 Faculty Management System

A clean, responsive web application to **organize faculty data and contact information** — add, search, edit, and delete faculty records, all stored right in the browser. Built with plain HTML, CSS, and JavaScript (no frameworks, no setup required).

> This project is part of my portfolio as a Computer Science Engineering student. It demonstrates core web-development concepts: DOM manipulation, CRUD operations, client-side data persistence, and responsive UI design.

---

## ✨ Features

- ➕ **Add** faculty members with name, department, designation, email, and phone
- 🔍 **Live search** across name, department, and email
- ✏️ **Edit** existing records inline
- 🗑️ **Delete** records with confirmation
- 💾 **Persistent storage** using the browser's `localStorage` (data survives refresh)
- 📱 **Responsive** layout that works on mobile and desktop
- 🛡️ Basic input sanitisation to prevent HTML injection

---

## 🛠️ Tech Stack

| Layer        | Technology              |
|--------------|-------------------------|
| Structure    | HTML5                   |
| Styling      | CSS3 (custom, responsive) |
| Logic        | Vanilla JavaScript (ES6) |
| Persistence  | Browser `localStorage`  |
